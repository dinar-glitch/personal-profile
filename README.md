# Dinar Verse — Personal Portfolio

A responsive, static HTML/CSS/JavaScript portfolio for Sajminul Haque Dinar. Designed for GitHub Pages.

## Features
- Responsive layout for desktop, tablet, and mobile.
- Inline SVG animated symbol constellation that cycles through creative intelligence, growth, Instagram-style content, engagement, and SEO/discovery. No external logo or image requests are required for these symbols.
- Tap the animated symbol on touch devices to cycle to the next icon. The ambient animation runs independently of mouse movement.
- Desktop-only custom cursor and magnetic interactions, with touch-friendly alternatives and reduced-motion support.
- Light/dark theme toggle.
- Interactive service links and service package contact modal with WhatsApp, email, and inquiry form options.
- Project inquiry form that prepares a message for email or WhatsApp. GitHub Pages does not store submissions by itself.

## Publish on GitHub Pages
1. Extract this project.
2. Upload `index.html`, `styles.css`, `script.js`, and the entire `assets` folder to the root of your GitHub repository.
3. Keep `assets/dinar-portrait.jpeg` in the same relative location.
4. Commit changes and wait for GitHub Pages to rebuild.
5. Refresh the live page with Ctrl+F5 if your browser shows a cached version.

## Notes
- All animated symbols are inline SVG, avoiding dependency on external image hosts or third-party logo loading.
- The motion respects the visitor's `prefers-reduced-motion` accessibility setting.
- Review contact details, service scope, package prices, and project examples before publishing.
